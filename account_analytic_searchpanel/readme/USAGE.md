1. Go to **Accounting > Configuration > Analytic Accounting > Analytic Plans**.
2. Enable **Show in Analytic Search Panel** on the dimensions that should be
   available for exploration.
3. Go to **Accounting > Analytic Accounting > Analytic Items**.
4. Use the left search panel to navigate the explorable analytic plan tree.
5. Review analytic lines grouped by Analytic Plan and Analytic Account.
6. To unfold the plan hierarchy, group by **Analytic Plan (Root)**, then
   **Analytic Plan (Level 1)**, **Analytic Plan (Level 2)** and so on.
7. Combine it with standard filters, groups, list, pivot, or graph views.
